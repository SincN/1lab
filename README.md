# Каталог автомобилей

Консольное приложение на Java: список машин из CSV-файла, добавление, удаление, фильтр по производителю.

## Меню

1. Показать список автомобилей
2. Добавить автомобиль (с проверкой данных, сохраняется в файл)
3. Обновить список из файла
4. Фильтр по производителю (Stream API: `filter`, `sorted`, `map`)
5. Удалить автомобиль по индексу (из списка и из файла)
6. Показать автомобиль по индексу
0. Выход

## Собственная коллекция

Машины хранятся в `CustomArrayList` — собственном аналоге ArrayList на массиве.
Реализованы `add`, `get`, `remove`, `size`; при заполнении массив автоматически расширяется вдвое.

## Файл с данными

`resources/cars.csv`, разделитель `;`:

```
manufacturer;model;year;power
Toyota;Camry;2019;181
```

Строки с ошибками пропускаются, причина выводится над меню.

## Проверка данных

- производитель и модель не пустые
- год от 1886 до текущего
- мощность больше нуля
